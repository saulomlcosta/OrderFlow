# OrderFlow

OrderFlow is a long-term software engineering laboratory.

The goal is not to build the most feature-rich commerce platform.

The goal is to start with a deliberately simple system and evolve it
as real engineering problems are discovered, reproduced, measured,
understood and solved.

## Core Principle

Do not introduce a technology without first identifying the problem
it is intended to solve.

## Learning Cycle

Problem
→ Reproduce
→ Measure
→ Understand
→ Research alternatives
→ Experiment
→ Compare
→ Decide
→ Document
→ Implement
→ Repeat
